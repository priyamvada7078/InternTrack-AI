# About the Project

**InternTrack AI** is a full-stack web application designed to help students manage their internship search from a single platform.

While applying for internships, students often have to keep track of different companies, roles, application dates, online assessments, interviews, offers, rejections, resumes, and follow-ups.

InternTrack AI brings this information together into one organized application.

The current version focuses on building a strong foundation with:

- User authentication
- Internship application management
- Dashboard
- Analytics
- Search
- Notifications
- Profile management
- Resume section
- Responsive UI
- Dark and light themes
- REST APIs
- MongoDB database

The next stage of the project will focus on integrating AI capabilities to make the platform more personalized and useful.

---

# Problem Statement

Managing internship applications manually can become difficult when the number of applications increases.

Students may use:

- Spreadsheets
- Notes
- Bookmarks
- Email
- Job portals
- Separate calendars

to keep track of the same internship search.

This makes it difficult to answer questions such as:

- How many internships have I applied to?
- Which companies are currently processing my applications?
- How many applications resulted in interviews?
- Which applications need follow-up?
- Which types of roles are performing better?
- What should I focus on next?

InternTrack AI aims to provide a single place where this information can be managed and analyzed.

# Project Goals

The main goals of InternTrack AI are:

1. Build a complete full-stack application.
2. Provide a centralized internship application tracker.
3. Make application progress easy to understand.
4. Provide useful analytics about the internship search.
5. Create a clean and responsive user experience.
6. Build a modular architecture that can be extended easily.
7. Integrate AI into the platform in the next stage of development.

## Internship Application Management

Users can manage their internship applications through:

- Add application
- Edit application
- Delete application
- View application details
- Search applications
- Filter applications
- Pagination
- Track application status

---

## Dashboard

The dashboard provides a summary of the user's internship search.

It includes:

- Total applications
- Interview count
- Offer count
- Rejection count
- Recent applications
- Upcoming interviews
- Recent activity
- Career momentum
- Application journey
- Next moves
- AI insight section

---

## Analytics

The analytics module is designed to help users understand their internship search through data.

It includes areas such as:

- Application statistics
- Application status distribution
- Interview progress
- Offer progress
- Rejection patterns
- Application activity
- Conversion-related insights

The analytics system will become more advanced once more real user data is available.
